Exportación y copias

La información se guarda en la base de datos compartida. Descarga copias de seguridad periódicamente; el plan gratuito no incluye copias automáticas.

Restaurar copia JSON

La restauración completa queda deshabilitada en modo multiusuario para evitar sobrescribir datos de otros compañeros.

Importar plantilla desde CSV

Cabeceras: matricula;nombre;apellidos;equipo;patron;ancla;activo. Acepta CSV UTF-8 separado por punto y coma o coma. No importa .xlsx directamente.

Importar permisos desde CSV

Cabeceras: matricula;codigo;desde;hasta;estado;notas. Fechas AAAA-MM-DD. Las matrículas deben existir.

Las copias JSON siguen disponibles para exportar. La importación global necesita una migración controlada.
